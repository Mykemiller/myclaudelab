# The Curiosity Workshop

Our family's makerspace for learning the ins and outs of Claude by building real projects together.
Live at https://myclaudelab.com

- `index.html` is the whole site: the photo workshop, the eight stations, the recipe box, the card catalog and the garden.
- `img/` holds the workshop photos.
- `content/` holds the shared workshop lessons and recipe cards every visitor sees. See `content/README.md` for how to add a day.

Every push to `main` deploys automatically through Vercel.
