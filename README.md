# The Curiosity Workshop

Our family's makerspace for learning Claude, from a first prompt to the top 10%.
Live at https://myclaudelab.com (family password).

- **The walk-in:** a scroll-driven tour from the street door into the hall.
- **The Hall:** 13 benches on three arcs (Hand Tools, Power Tools, Shop Automation). Each bench has a what-is-it card, a watch block, a recipe card, Spark / Build / Invent challenges with done-when checks and hints, a "now question it" self-check, and a shop rule.
- **The Director's Desk:** this week's chalkboard, the Lab Director's clips (an AI video avatar at four benches, renewed weekly), the next suggested bench and flash cards.
- **Your Path:** the Maker Ladder (Visitor, Apprentice, Journeyman, Craftsperson, Master Maker), the Tool Cage, the Tool Belt Check and four explorer's paths.
- **Recipe Box, Card Catalog, Replay Theater and the Garden.**

Progress is kept in each browser, one set per learner. Content lives in `content/` (see `content/README.md`). Every push to `main` deploys automatically through Vercel.
